# CONTEXTO DEL PROYECTO (OPERACIÓN FOODTRUCK - NIGHTBITE)

Este archivo contiene el cerebro y la memoria principal del proyecto.

## Arquitectura Base
- **Frontend**: Vite + React + Tailwind + Motion (`/frontend`).
- **Backend**: Cloudflare Workers + D1 (`/backend`).
- **Real-Time**: Server-Sent Events (SSE) para el tablero de órdenes.
- **Seguridad**: JWT por entorno para Admin Panel. `cyber_operator` activo para pentesting.
- **Ejecución**: Uso estricto de `npx.cmd`.

## Enjambre de Agentes
1. `motion_frontend`: Diseñador de React, oscuro, acelerado por hardware. (Ref: skill `motion-dev`).
2. `edge_backend`: Arquitecto Node.js/Cloudflare.
3. `cyber_operator`: Pentester. (Ref: skill `cyber-ops`, herramientas: `hackbrowser`, `cheatengine`).
